# UI Components

Use shadcn/ui components for all interface controls and visual UI elements. Reuse the existing components in `components/ui` and their supported variants.

Do not create custom UI components or hand-roll replacements for shadcn/ui components. If a needed component is not present, add the shadcn/ui component using the project's shadcn setup, then use it. Use semantic HTML for page structure and the configured Lucide icon library for icons.
